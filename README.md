## About

Project Equilibrium is a calm, focused space for checking in with yourself. It guides you through breathing exercises, lets you log how you're feeling on a 2D emotional grid, and gives you a place to journal — then turns the past week of check-ins into a mood history scatter plot, so patterns become visible instead of forgotten. Everything is stored locally in your browser, so there's nothing to sign up for and nothing leaves your device.

<br>

## ✨ Features

- **Guided breathing exercises** — a dedicated breathing control panel walks you through the exercise in real time
- **Mood tracking** — plot how you're feeling on a 2D emotional grid instead of picking from a flat list of moods
- **Journaling** — write freeform entries alongside your mood check-ins
- **7-day mood history** — a scatter plot view of your recent check-ins, so trends are easy to spot
- **Fully local & private** — all data is saved in the browser, no account, no server, no tracking
- **Calm, considered visual design** — built around an Olive & White meditation aesthetic, with animated, low-distraction UI

## 🛠️ Tech Stack

<p align="center">
  <img src="https://skillicons.dev/icons?i=react,vite,tailwind,javascript&theme=dark" />
</p>

Built with React 18 and Vite, styled with Tailwind CSS, and using [Lucide](https://lucide.dev) for icons. No charting library — the mood scatter plot is custom-built rather than dropped in from a package.

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/Purvpatel1/Project-Equillirium.git
cd Project-Equillirium
npm install
```

Run the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
